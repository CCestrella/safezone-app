# SafeZone

SafeZone is a mining safety intelligence prototype designed to help workers and supervisors identify hazards, visualise risk exposure, and make safer operational decisions in real time.

## Overview

Mining environments contain constantly changing risks including:

- Falling objects
- Equipment interactions
- Restricted zones
- Active work fronts
- Traffic and vehicle movement
- Environmental hazards

SafeZone brings critical safety information together in a single interface, enabling faster hazard awareness and more informed decision-making.

## Features

### Safety Dashboard
- Live site safety overview
- Active hazard monitoring
- Open actions and incident tracking
- Operational safety telemetry

### Hazard Intelligence
- Falling object alerts
- Near miss monitoring
- Critical risk notifications
- Safety trend visualisation

### Worker Visibility
- Worker location awareness
- Team activity view
- Incident evidence management
- Worker status tracking

### Interactive Site Map
- Hazard heatmaps
- Risk zones
- Active work areas
- Asset and personnel visibility

### Incident Management
- Report hazards
- Capture evidence
- Track investigations
- Monitor corrective actions
